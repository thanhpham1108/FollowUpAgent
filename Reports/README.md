# Reports

Thư mục này được lưu trong Git, tách khỏi code chạy trong `backend/`.

- [`weekly/`](weekly/): báo cáo theo tuần và các bản theo dõi tiến độ cũ.
- [`slides/`](slides/): bài trình bày và PDF báo cáo.
- [`reference/`](reference/): tài liệu API và đề xuất tích hợp.
- [`assets/`](assets/): hình dùng trong báo cáo.

Nội dung theo tuần là bản ghi tại thời điểm viết; tên file, lệnh và reason code trong các bản cũ có thể khác code hiện hành. Hướng dẫn đang dùng nằm trong [`thanh-workspace/`](../thanh-workspace/README.md).
