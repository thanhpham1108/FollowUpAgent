## API Contract — End-to-end Flow

1) CRM -> AI: `POST /api/v1/candidates/analyze` with JSON body:

```json
{
  "ssn": "079099123456",
  "candidate_name": "Nguyen Van A",
  "audio_url": "http://<crm_server_ip>/files/079099123456_interview.mp3"
}
```

Response: `202 Accepted` with `task_id` (queued).

2) AI -> CRM webhook: `POST /webhook/candidate-recommendation` when processing completes.

Example payload includes `task_id`, `ssn`, `status`, and `result.summary` + `recommended_message`.
