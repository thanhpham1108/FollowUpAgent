## 3. Key Findings

- **Tesla P100 Architecture (`sm_60`)**: Default PyTorch 2.2+ (CUDA 12) wheels dropped `sm_60` binary kernels, causing silent fallback to CPU. PyTorch `2.1.2+cu118` is the optimal build supporting Pascal through Ada Lovelace.
- **Ollama Runner**: Ollama v0.33.2 skips `cuda_v13` for `sm_60`, but successfully falls back to internal `cuda_v12` runner — detects `Tesla P100-PCIE-16GB` with 15.9 GiB VRAM (100% GPU).
- **Domain-Specific Proper Noun Recognition**: Fine-tuning PhoWhisper on company names is **unnecessary and high-risk** (catastrophic forgetting). Hybrid of regex post-processing (`text_normalizer.py`) + LLM prompt context injection (`analysis_prompts.py`) handles 95%+ of naming inaccuracies in real time.
- **Git Repo State**: Local repo has `Reports/` in `.gitignore`. Code commits exist on `main` (commit `462454a`).

| `torchvision` `AttributeError: module 'torch.library' has no attribute 'register_fake'` | `torchvision 0.29.0` compiled for PyTorch 2.14, incompatible with `torch 2.1.2` | `pip uninstall -y torchvision` |
